# 酒馆小程序主界面：三种视觉方向

这一轮只比较主界面风格，品牌暂用“慢半拍 / SLOW SIDE”。全部酒单、对话、杯垫选择均为 mock，浏览器预览不调用酒馆业务接口、不登录顾客、不下单。

启动前端后打开 `http://127.0.0.1:5173/bar-concepts`，可以并排比较。单独预览使用 `?style=vinyl`、`?style=taproom`、`?style=quiet`。

| 方向 | 视觉与布局 | 场景气质 |
|---|---|---|
| 深夜唱片酒馆 | 墨绿底、琥珀橙、唱片播放标记、纸质调酒师便签 | 适合聊天、听音乐、慢慢喝 |
| 复古美式精酿吧 | 砖红底、奶油黄、粗体海报、鲜打酒头编号、票据酒单 | 热闹、有活力、突出精酿 |
| 日式隐秘小酒馆 | 米白底、炭黑宋体、拱形酒杯特写、细线和留白 | 安静、亲近、重视调酒细节 |

三版使用同一份 mock 酒单和推荐场景，底部固定对话输入，菜单作为调酒师推荐的延伸；支持输入“微甜无酒精”、切换鸡尾酒/精酿、查看酒款、加入本次杯垫并清空。

素材位于 `frontend/public/bar-concepts/`，图源见其中的 `credits.md`。效果图输出到被 Git 忽略的 `artifacts/bar-concepts/`。在项目根目录运行常规检查后，可以用以下命令重新生成：

```bash
cd frontend
npm run test:e2e -- bar-concepts.spec.ts
```

## 已选方向：01 深夜唱片酒馆

用户已选 01。原生微信小程序首页已采用墨绿、琥珀橙、唱片标记、纸质调酒师便签和摄影酒单；杯垫与口味页同步使用深绿配色。品牌“慢半拍”仍为临时名称。

浏览器直接体验：`http://127.0.0.1:5173/bar`。三版比较页继续保留。新版支持酒款详情、分类、杯垫本地保存，以及从已完成订单推测“老样子”、展示依据并确认加入。浏览器体验与原生小程序的本地缓存独立。

“我的杯垫”已与 01 统一：墨绿全屏画布、唱片品牌标记、宋体标题、带胶带的纸质酒单、酒款摄影、细虚线和琥珀色主按钮。酒单支持数量调整、逐款移除和实时小计；空杯垫也使用同一套视觉。原生页同步采用该布局。杯垫截图位于 `artifacts/bar-home/03-coaster.png`、`04-coaster-empty.png` 和 `05-coaster-small.png`。

`miniprogram/config.js` 默认 `mockMode: true`，无需后端和微信登录即可体验虚构酒单和明确标注的虚构订单，数据仅写入本机 `slow_side_mock_v1` 缓存；不会创建订单或产生真实消费记录。切换 `mockMode: false` 后恢复服务端 API 流程。原生 mock 支持无酒精、微甜、鸡尾酒/精酿、数字预算、忌口和基于已完成订单推测的常喝酒款；当前为规则 mock，尚未接入真实订单或大模型习惯分析。

验证：`bash scripts/check.sh` 包含原生离线页面逻辑验收；`cd frontend && npm run test:e2e -- bar-home.spec.ts bar-concepts.spec.ts` 验收手机浏览器交互并输出 `artifacts/bar-home/` 截图。WXML/WXSS 已通过本机微信编译器。当前微信开发者工具导入时提示游客 AppID 不受支持，因此尚未完成原生模拟器视觉验收，需使用自己的有效小程序 AppID 后继续。
